# Contributing

Start with [AGENTS.md](AGENTS.md) and the documentation for the area you are changing. Keep changes focused. Add meaningful tests for new logic, run `npm test` and `npm run build`, and verify affected UI flows in a real browser. Include verification results and external-tool limitations in pull requests.

Never commit local projects, media, credentials, personal paths or provider settings. Preserve upstream notices for reused open-source components. Contributions are provided under the MIT license.
