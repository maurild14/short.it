# README media

These assets were recorded from the real short.it editor for its documentation on 16 November 2026. The original three-scene sample uses editable text and shapes in the app's bundled Montserrat and Space Mono fonts. It was created specifically for these captures in an isolated local workspace; no personal project, narration, reference video, transcript or provider conversation is included.

| Asset | Content |
| --- | --- |
| `short-it-logo-dark.png`, `short-it-logo-light.png` | The application's existing wordmark, rendered with transparent backgrounds for GitHub's dark and light themes |
| `short-it-editor.gif` | Changing a headline, dragging it, seeking between scenes and entering fullscreen preview |
| `short-it-canvas.gif` | Editing text, moving and resizing the headline, undoing and redoing |
| `short-it-timeline.gif` | Expanding the timeline, trimming, moving and splitting a clip, then seeking |
| `short-it-media.gif` | Importing the demo's cover image, adding it as a layer and mentioning it in a draft prompt |
| `short-it-workspace.gif` | Resizing panels, collapsing the assistant and entering fullscreen preview |
| `short-it-workspace.png` | A still of the editor with the first scene visible |
| `short-it-scenes.png` | The three demo scenes captured from the canvas and arranged side by side |
| `short-it-poster.png` | The first scene, also used as `cover-art.png` in the media-import recording |

The recordings use a visible pointer overlay for readability. Fullscreen captures use the app's built-in expanded-preview fallback to stay within the recorder's viewport. Interactions run against the local application and API; chat prompts in the media demo remain drafts. No paid agent turn, reference download or MP4 export was performed for these recordings. The GIFs are silent, loop automatically and link to their full-size files from the main README.

The sample's runtime project and raw recordings are kept out of Git. Only the documentation images and GIFs belong in this directory. Font licenses remain under [`public/fonts/`](../public/fonts/).

No personal projects, external media, or assistant conversations are included.
